投稿する人のための、写真が主役の画面

発起人の回答（投稿する人が主役／スマホでその場から／まず多くの人に／change.org・画像・負担の少なさ）から組みました。実際に投稿されている Issue をそのまま使っています。

1. 何を変えるか

「殺風景」の正体は装飾不足ではなく、カードに写真と「何人が動いているか」が無いことでした。change.org のカードはこの2つで趣旨を一瞬で伝えています。色を足すより、この2つを足す方が効きます。

2. 写真が無いときも空白にしない

写真は必須にしません（その場で撮れないこともあるため）。無いときは地図の切り抜きを代わりに置き、カードの形が崩れないようにします。文字だけの列に戻さないための措置です。

3. 投稿の負担を減らす

「趣旨の理解に負担が少ないこと」は、読む側だけでなく書く側にも効きます。いま最初に出る項目は「タイトル」ですが、見本では写真から始めます。撮って出すのが一番軽く、写真があれば説明も短く済むためです。座標は自動で入り、数値は表に出しません。

4. 配色

主役は緑を1色だけ。「直す」「草木」「動き出す合図」に繋がる色です。ニュートラルも緑に寄せた温かいグレーにして、純グレーの「未設定な感じ」を避けています。状態の色（受付・対応中・解決）は主役とは別系統にして、意味を持たせています。

5. 文字の段階

5段階だけに絞ります。段階が多いと、どれを使うか毎回迷って揃わなくなります。書体は端末に入っているものを使い、読み込みを増やしません（表示が速い方が、負担が少ない）。

28px / 700ページの見出し
17px / 700カードの見出し
16px / 400本文。長い説明はこの大きさで読みます
14px / 400補助。カードの説明文、フォームの注記
12px / 700ラベル。状態、日付、区分

6. この見本に含まれない前提

写真の機能はまだ実装されていません（Issue #65、ストレージ未選定）。この見本は「写真が入る前提」で組んでいるので、採用する場合は #65 を先に進める必要があります。

「何人が手伝います」の表示は #61 で実装済みのデータが使えます。地図は #63 の PR が出ているので、写真が無いときの代役に流用できます。

見本です。実装前なので、この段階の修正にコストはかかりません。色・文字の大きさ・並べ方、どこでも変えられます。
